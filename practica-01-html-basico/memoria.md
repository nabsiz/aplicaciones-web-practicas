# Práctica 1 – Introducción a HTML básico

## Objetivo
Crear una estructura básica de página web utilizando etiquetas estándar de HTML5.

## Desarrollo
1. Estructuración del documento con las etiquetas `<!DOCTYPE html>`, `<html>`, `<head>` y `<body>`.
2. Inclusión de encabezados (`<h1>`, `<h2>`), párrafos (`<p>`) y enlaces (`<a>`).

```html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi Primera Web</title>
</head>
<body>
  <h1>Hola Mundo</h1>
</body>
</html>
